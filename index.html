Context

A few clients are hammering your team's public API. Build the per-key rate limiter the gateway calls on every request.

Requirements

  • allow(key) says whether this request goes through, and when to retry if not.
  • A key can burst up to burst requests, then earns tokens back at ratePerMinute.
  • Time is injected through now so tests can control it.
  • Keys are independent.

Left open on purpose

Memory with millions of keys. Running on several servers. What counts as a client. Decide, then write what you chose and why in README.md.
